# Inventory Management System

A simple inventory management system built with Python and Flask. It provides a REST API for managing products and also includes a command-line interface.

## Features

- View all inventory items
- View a single inventory item
- Add a new item
- Update an item
- Delete an item
- Look up product information using OpenFoodFacts
- Command-line interface
- Automated tests using pytest

## Requirements

- Python 3
- Flask
- Requests
- Pytest
